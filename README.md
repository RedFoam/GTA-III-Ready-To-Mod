# Grand Theft Auto III — Ready to Mod 🌆

## Everything You Need in One Place

This project was created to make **Grand Theft Auto III Classic for PC** easier to set up and enjoy on modern hardware.

Instead of searching across multiple websites for patches, compatibility fixes, plugins, and improvements, this project aims to bring the essential resources together in one convenient place.

The goal is simple: **download the pack, copy the files into your GTA III game folder, and get ready to play.**

This setup targets the classic PC retail v1.0 executable and focuses on bug fixes, widescreen support, controller compatibility, audio improvements, and enhanced visuals while preserving the original GTA III experience.

## 🚀 Installation

Getting started is designed to be simple!

1. Download this repository.
2. Open your GTA III installation folder — the folder containing `gta3.exe`.
3. **Copy the files and folders from this pack into your GTA III game folder.**
4. Allow folders to merge if Windows asks.
5. Launch the game and enjoy!

Keep the included folder structure intact so each mod's files remain in their intended locations.

**Important:** Some mods require files to be placed in specific subfolders, such as `scripts`, rather than directly in the game root. The pack must be arranged correctly before the copy-and-play installation process will work.

## ⚙️ Requirements

- A legitimate PC copy of Grand Theft Auto III Classic.
- The intended classic PC executable, preferably retail v1.0 for this setup.
- Windows PC.

## ⚠️ Important Notes

- Back up your original game files and save files before installing.
- This project is intended for classic GTA III, not GTA: The Trilogy – The Definitive Edition.
- Compatibility depends on the exact game executable and mod versions.
- Avoid installing competing ASI loaders or graphics wrappers without checking compatibility.
- Optional mods may require additional dependencies or configuration.
- The pack should be tested as a complete installation before being advertised as fully plug-and-play.
